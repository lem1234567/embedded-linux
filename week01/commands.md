# Week 1 · Linux 命令练习

## Day 1（10/19）

### pwd — 我在哪
pwd获取目前所在位置路径

### ls 列出当前目录下的文件
-l 显示文件详细信息（包括权限、所属用户、文件大小、时间、文件名），-h 大小显示成 4.0K 这种，-a 显示隐藏文件。

### cd 到达指定目录
cd ..返回上一层目录
cd ~返回根目录
cd ../.. 返回上两层目录
cd - 返回上次使用的目录

### tree — 整体结构
以当前目录为根节点以树状结构显示其下文件
tree -L 1 只显示一层目录
tree -d -L 1 只看往下一层的目录，不看文件

### less 查看文件内容
例：less README.MD
空格  下一页
/关键词  搜索关键词（如/week)
n  跳转到下一个匹配
q  退出
